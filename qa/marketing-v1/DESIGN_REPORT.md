# Public website design report

The public experience now uses an editorial black/near-white rhythm, disciplined display type, one restrained lime accent, real product-shaped UI compositions, a permanent-QR story, operational journey, pricing, FAQ and a compact footer. Glass is limited to the header and floating CTA treatment; content sections remain solid and quiet.

The existing `/q/:publicId` and `/b/:slug` customer experience remains a separate business-branded surface. The marketing site never exposes tenant data or private console content.
